# AI-SDN Anomaly Detection System

## Overview

AI-SDN Anomaly Detection System is a cybersecurity project designed to detect anomalous behavior in Software Defined Networks (SDN) using Machine Learning and Artificial Intelligence.

The system monitors network and system metrics in real time, identifies suspicious activities using an Isolation Forest model, and generates intelligent security reports to assist network administrators in incident response.

This project was developed as a Final Year Project (PFE) in Network Security and Cybersecurity.

---

## Features

### Real-Time Monitoring

* Continuous collection of system and network metrics.
* Live anomaly detection.

### Machine Learning Detection

* Isolation Forest algorithm.
* Automatic identification of abnormal behavior.
* Decision score evaluation.

### AI-Powered Analysis

* Security incident interpretation using Gemini AI.
* Risk level classification.
* Attack explanation and impact assessment.
* Recommended mitigation actions.

### Dashboard Interface

* Web-based monitoring dashboard.
* Alert visualization.
* Historical anomaly tracking.

### Reporting

* Automatic anomaly reports.
* CSV logging.
* JSONL event storage.
